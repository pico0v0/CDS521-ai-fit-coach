# 开合跳运动学精修说明（v0.2.1 / 2026-11-06）

## 0. 输入与证据范围

检查了三段用户上传的开合跳合成骨架录屏：`开合跳1 手腿脱节.mp4`、`开合跳2双臂不对称.mp4`、`开合跳3腿未展开.mp4`，分别约 8.13s、5.43s、4.80s，1280×720/30fps。它们是应用录屏，并非真人的可用于准确 2D/3D 人体姿态估计的独立相机视频。因此此改动是对原动画轨迹的几何重建及错误语义再设计，并不宣称提取了真实人体的精确关节坐标或三维生物力学参数。

发现旧动画的主要问题：
- `x/y` 归一化坐标被当作各向同性平面角计算；960×540 实际渲染比例下，画面骨骼角度和分析器角度不一致。
- 双脚沿固定高度直接左右平移，膝点被另行插值，出现腿段长度变化，且无起跳、滞空或落地屈膝。
- 双臂默认峰值 140°，手腕未举过头顶，表现近似僵硬 T 字形。
- 错误代偿在固定时窗突开突关，单臂滞后时的瞬间姿势虽然报警，但该轮仍可能被计为标准次数。

## 1. 坐标系统与刚体链

对所有被修订的开合跳动作，先在 **960×540 像素**下求解，再仅在写入 MediaPipe 风格关键点时执行：`x = px / 960; y = py / 540`。

| 骨段 | 长度 px |
|---|---:|
| 左/右上臂（肩→肘） | 76.00 |
| 左/右前臂（肘→腕） | 76.00 |
| 左/右大腿（髋→膝） | 101.00 |
| 左/右小腿（膝→踝） | 110.00 |
| 左/右躯干（髋→肩） | `hypot(12,113)` ≈ 113.635 |
| 左/右脚尖（踝→脚尖） | 25.00 |
| 左/右脚跟（踝→脚跟） | 13.00 |
| 头中心→肩中点 | 59.00 |

所有骨段由同一套解析二连杆圆交法求解。对于固定起点 `A`、终点 `B`、第一段 `L1`、第二段 `L2`：

```text
D = B - A
r = ||D||
u = D / r
q = (L1² - L2² + r²) / (2r)
h = sqrt(L1² - q²)
K = A + q*u ± h*(-u_y, u_x)
```

其中 `±` 对应左右膝或肘的解支。实际计算检查 `|L1-L2| ≤ r ≤ L1+L2`，一旦不可达就报错，**绝不通过拉长骨骼补偿**。两侧肩髋一同平移，肩髋间横向偏移固定为 12px，竖向固定为 113px。

### 角度统一

开合跳左臂角为 `angleDegrees(leftHipPx,leftShoulderPx,leftWristPx)`，右臂同理；`extractJointAngle()` 的展示角是这两个实际像素角的平均值（最后四舍五入显示）。在非对称错误中，模拟器的名义角度 `simulatedAngle()` 是**左臂的驱动目标**；故意滞后的右臂有自己的角，分析器返回两侧实际角度的平均值，这是正确而非数值不一致。为了抵消肩髋横向偏移，手腕的世界朝向扣除了 `atan2(12,113)`，因此正常动画单侧实际角度等于目标角度，误差处于浮点舍入范围。

## 2. 4700ms 动作时序

- 初始：双手放低约 25°，双足自然站立。
- `t≈0.11–0.34`：起跳准备阶段与轻微屈髋屈膝。
- `t≈0.18–0.46`：手臂沿平滑弧线举起，双腿同步外展。
- `t≈0.22–0.79`：空中动态；离地曲线是两端二阶导数连续的 quintic 上下行包络，**无原来长时间的悬空定格**，最大离地约 31px。
- `t≈0.46–0.57`：双臂峰值停留（方便观察），双腿开始准备收拢；峰值标准姿势双臂约 168°，双脚宽度约为髋距 3.00 倍。
- `t≈0.76–0.90`：落地吸震，膝盖自然微屈，之后恢复初始姿势；`t=0` 和 `t=1` 所有关节严格一致。

不同难度的**动画目标角**分别为：初学 160°、标准 168°、进阶 173°，均超过分析器设置的不同难度达标阈值。旧版 140° 因为画面上并未真正举过头顶而被调整。旧版普通模拟模式每四次保留一次较小幅度的练习轮次，以维护既有回归测试。

## 3. 三种错误的运动学与识别闭环

| 错误 | 连续错误表现 | 提示与最终规则 |
|---|---|---|
| 01 `asymmetry_or_desync` | 手臂按正常节奏上举；腿直到 `t≈0.59` 才开始外展，并于 `t≈0.77` 达峰，此时手臂已回落 | 双臂均高于 132° 且瞬时脚踝/髋距比 <1.38 时提示；状态机记录臂峰脚未展开，结束不计数 |
| 02 `arm_asymmetry` | 左臂正常；右臂在 `t≈0.45–0.58` 连续落后，峰值左右差约 74°，没有突然改变骨长或重设关节 | 左右实际像素角差 >35°，全轮记录异常，结束不计数 |
| 03 `static_legs` | 脚踝始终固定，只有轻度原地屈膝与上肢动作；四肢长度不变 | 单帧可能仅识别出“手举高腿没开”，**只有全周期**看到 `peakLegSpread < 1.45` 且 `peakAnkleDist-minAnkleDist < 0.035` 才能严格分类 `static_legs`，结束不计数 |

**重要区分：** 在双手举高而腿尚未外展的**单帧**，错误 01 与错误 03 不具有足够可辨识的几何差异。避免将预设的 `faultIndex` 偷带给识别器。现在 `checkPostureFault(landmarks, 'jumping_jack', side, history)` 能消费来自 `ExerciseAnalyzer` 的真实轨迹累计统计：静止脚与迟到脚的最终分类由一整轮运动事实决定，而不是仅凭错误模式标签。`ExerciseAnalyzer` 同时记住整轮的 `arm_asymmetry`，避免 “即时报警但最终错误地计为合格”。

## 4. 绘制与集成

- `src/simulator.js`：开合跳像素刚体 IK、自然离地与屈膝包络、三类错误的连续轨迹；深蹲及弯举此前精修未改。
- `src/exercise.js`：开合跳角度改成与 Canvas 一致的 960×540 像素角；增补历史分类与不合格次数拦截。
- `src/draw.js`：开合跳地面参考线固定，不再随离地脚踝一起“浮起来”。
- `server.mjs`：安全地仅将 `/preview.html` 新增到静态白名单；不放开目录访问。
- `preview.html`：正确动作与任选错误动作并排逐帧预览，支持暂停、拖动进度条和难度选择。
- `tests/jumping-jack-refine.test.mjs`：增加 6 个专项回归用例，含所有模式×所有难度×每 1ms 骨长与连续性扫描。
- `scripts/smoke.mjs`：确认预览页面能通过服务器 GET/HEAD 访问，现有安全拒绝规则未放松。

### 运行方式

```bash
npm run dev
# 浏览器打开 http://127.0.0.1:4173/preview.html
npm run check
npm test
npm run smoke
```

## 5. 实测数值（最终版）

对 `standard` + 3 种故障、3 种难度，按每毫秒取样 0–4700ms，检查了腕/肘、膝/踝、肩/髋、踝/脚尖与踝/脚跟：

- 最大骨长误差：`2.1316282072803006e-13 px`（浮点舍入）。
- 非故意不对称动作的单臂角度与目标角度最大差：`1.9895196601282805e-13°`。
- 相邻 1ms 关节点最大位移：`0.58843 px`（无瞬间跳帧）。
- 周期接缝：`simulatePose(0) == simulatePose(4700)`；位姿循环一致。
- 标准：1 次有效；错误 01/02/03：各 0 次有效、1 次不合格，最终分别收到对应代码。
- `npm test`：50/50；`npm run check` 与 `npm run smoke`：通过。

**局限：** 这些是固定 2D 像素投影的演示约束，不是三维人体动力学，也不意味着合成数据能直接作为真实人体的安全诊断证据。提供的并排 MP4 是由同一份合成关键点驱动的独立视频可视化，不是浏览器 Canvas 渲染录屏，发光效果可稍有差异。
