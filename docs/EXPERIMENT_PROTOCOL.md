# 真实受试者对照实验实施规范与误差分析指南（M3 交付项）

> **适用场景**：AI 视觉健身课程设计 / 学术论文实验章节 / 课程汇报第 12–13 页对照实验。  
> **核心规范**：真实受试者知情同意、严谨人工标注基准（Ground Truth）、明确分离模拟数据、公开典型失效案例（可解释性）。

---

## 一、实验方案与受试者设计

### 1. 受试者要求（知情同意）
- 按照课程规范招募 **至少 3 名匿名受试者**（代号 P01, P02, P03）；
- 所有受试者在实验前充分知悉实验目的、姿态估计仅用于课程研究、视频流与数据 100% 留存在本地设备不上传任何云端服务器，并签署/确认知情同意。

### 2. 实验变量矩阵（多环境鲁棒性检验）

| 变量维度 | 设定参数组 A（基准环境） | 设定参数组 B（挑战环境） | 实验考察目的 |
| :--- | :--- | :--- | :--- |
| **拍摄机位** | 标准侧面 $90^\circ$（深蹲/弯举） / 正面（开合跳） | 斜向 $45^\circ$ 机位 | 检验 2D 单目透视投影对几何测角的影响 |
| **光照条件** | 室内充足顶光均匀漫射 | 强逆光 / 弱光背光 | 检验边缘对比度下降时关键点置信度与抖动 |
| **受试衣着** | 适度贴身运动服 | 宽松阔腿裤 / 宽松长袖 | 检验衣物遮挡对关节几何中心回归的干扰 |

### 3. 数据集采集规格
- 每个受试者针对 **深蹲、哑铃弯举、开合跳** 3 种动作，各完成至少 **10 次动作**（建议包含 8 次标准动作 + 2 次刻意浅幅度动作以测试辨识力）；
- 由实验裁判员手持计数器同步记录真实完成次数（Ground Truth）。

## 二、评测数学指标体系

### 1. 平均绝对误差（Mean Absolute Error, MAE）
$$\text{MAE} = \frac{1}{N} \sum_{i=1}^N \left| \hat{y}_i - y_i \right|$$
- $\hat{y}_i$：AI Fit Coach 系统记录的有效达标次数；
- $y_i$：人工观察裁定的真实完整动作次数；
- $N$：实验样本总轮次。

### 2. 浅动作辨识召回率（Shallow Rep Recall）
$$\text{Recall}_{\text{shallow}} = \frac{\text{TP}_{\text{shallow}}}{\text{TP}_{\text{shallow}} + \text{FN}_{\text{shallow}}}$$
- 评估当受试者动作未达到达标阈值（如深蹲未蹲深、弯举未充分屈肘）时，系统是否能 100% 准确将其判入“未达幅度”而不计入有效次数。

## 三、四大典型失效案例（可解释性复盘）

在答辩与实验报告中，**主动披露并深入分析失败案例是高分答辩的关键**：

```
                [2D 成像投影]
                 /         \
   [透视角度缩水 45°]      [宽松衣物遮挡]
        |                        |
   测算角度偏大             关节点向外偏移
   (下潜深度被低估)         (测角抖动噪点)
```

### 案例 1：透视投影角畸变（机位偏斜 $45^\circ$）
- **现象**：受试者实际已下潜到位（真身膝角 $100^\circ$），但系统显示膝角为 $120^\circ$，导致动作被误判为未达标。
- **根因分析**：单目 RGB 摄像头将三维世界投影为二维像平面。当拍摄夹角偏离人体运动矢状面 $45^\circ$ 时，向量沿视线方向的深度信息被压缩，计算所得的 2D 投影夹角在数学上必然大于真实的三维立体解剖学夹角。
- **优化与建议**：系统内置「机位建议」；在后续版本中可引入预定标校准算法进行射影几何补偿。

### 案例 2：宽松阔腿衣物遮挡（Clothing Occlusion）
- **现象**：穿肥大阔腿裤做深蹲时，系统关节连线发生微幅漂移。
- **根因分析**：MediaPipe 姿态模型依赖人体体表视觉轮廓回归骨骼中心点。极度肥大的裤腿遮挡了膝关节真实旋转中心，热图响应峰值发生偏移。
- **优化与建议**：系统引入了 `lastSmooth * 0.55 + angle * 0.45` EMA 滤波，有效抑制了单帧跳点；建议用户穿着相对贴身或轮廓清晰的运动服装。

### 案例 3：高速动作与单帧运动模糊（Motion Blur）
- **现象**：极快速跳跃时（开合跳），手腕关键点可见度瞬时跌破 0.4。
- **根因分析**：普通家用网络摄像头（曝光时间长）在高速运动下产生边缘拖影。
- **优化与建议**：状态机设置了 `MIN_REP_MS = 650ms` 避免超高速突变噪点误计数，并在手腕可见度下降时平滑退化至单侧或等待站稳。

### 案例 4：肢体重叠自遮挡与迟滞锁定（Hysteresis）
- **现象**：侧对镜头深蹲时，内侧腿在上升过程中被外侧腿完全遮挡。
- **系统表现**：系统成功触发迟滞锁定策略（`preferredSide` + `hysteresis = 0.12`），稳定锁定在外侧腿上，全程未出现左右腿抖动跳变。

## 四、实验数据采录与一键分析 SOP

利用 AI Fit Coach v0.2.0 内建的实验评测链路，可在 5 分钟内完成标准化学术数据导出：

1. **录制或实时采集**：
   - 方式 A：打开「启动 AI 摄像头」直接实地训练；
   - 方式 B：用手机拍摄受试者高清视频，点击「🎞 本地视频评测」导入系统逐帧推理。
2. **记录人工观察基准**：
   - 动作完成后点击「结束训练」；
   - 在弹出的对照实验提示框中，输入裁判员记录的真实完成次数（例如 `10`），留空则视为普通练习。
3. **查看与导出对比报告**：
   - 进入「训练报告」页面，右上角会自动汇算 **实验对照 MAE** 指标；
   - 点击 **「⤓ 导出 CSV」**，直接导出带有 UTF-8 BOM 的 Excel 兼容表格；
   - 表格内已自动填充 `系统有效次数`、`人工对照次数` 与 `绝对误差`，可直接复制粘贴到课设大作业或毕业设计论文中！
