## 三、强调：不是 Bug 的设计决定与边界声明

1. **零外部 npm 构建依赖**：坚持原生 ES Modules、纯原生 Node.js 内置模块与 Web API，不引入复杂打包器。
2. **合成模拟模式（`mode: 'demo'`）绝对不运行 AI**：仅用于 UI 流程演示与状态机回归测试，其数据在看板和报表中与真实 AI 物理隔离。
3. **姿态纠错建议由规则模板生成，非云端大模型生成**。
4. **严格不提供任何基于摄像头的医疗损伤诊断或处方预测**。
